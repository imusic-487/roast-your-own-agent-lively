## What it does

`main.py` writes a single line — one roast of the entrant's own AI agent,
at most 140 characters — to `/output/entry.txt`.

> My agent confidently debugged a file that doesn't exist, apologised for the confusion, then asked me to confirm it had fixed it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no secrets, no dependencies — just the Python standard library.
